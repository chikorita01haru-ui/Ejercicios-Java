# Ejercicios de Java

Este repositorio contiene una colección de ejercicios básicos y prácticos en Java, enfocados en reforzar la lógica de programación y los fundamentos del lenguaje.

---

## Contenido

Los ejercicios incluyen:

- 🔢 Operaciones básicas
- 🔀 Condicionales (if, else, switch)
- 🔁 Ciclos (for, while, do-while)
- 🧩 Lógica de programación
- 📥 Entrada de datos con Scanner
- 📊 Ejercicios prácticos

---

## Requisitos

Para ejecutar los ejercicios necesitas:

- Java JDK instalado
- Visual Studio Code (opcional)
- Terminal o consola

---

## Cómo ejecutar

1. Compila el archivo:

```bash
java NombreArchivo.java
```
